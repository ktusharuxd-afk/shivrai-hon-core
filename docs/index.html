⚡ Shivrai Hon Core

A complete blockchain node in C++17

Quick Start

git clone https://github.com/ktusharuxd-afk/shivrai-hon-core.git
cd shivrai-hon-core
bash scripts/build.sh
bash scripts/run_node.sh

Then open http://localhost:8545/

Features

  • PoA consensus — 3s blocks
  • ECDSA secp256k1 accounts + signature verification
  • Nonce replay protection + balance check
  • SQLite WAL persistence, batched per block
  • JSON-RPC 2.0 + REST alias
  • P2P block gossip via --peer
  • 10 modules: chain, stablecoin, lending, governance, token, NFT, AMM, staking, multisig, p2p
  • Web explorer + browser wallet
  • Docker, CI, benchmark, CLI, Python SDK
