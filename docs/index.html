A self-contained node with all the primitives for real-world blockchain applications.

Dual Consensus

Proof-of-Authority for speed, Proof-of-Stake with stake-weighted leader selection.

🔐

ECDSA Accounts

secp256k1 signatures verified on-chain. Nonce replay protection + balance checks.

📦

WASM Contracts

Embedded wasm3 runtime. Deploy, call, and meter gas for smart contracts.

💾

SQLite Persistence

WAL mode with batched writes per block. State survives restart reliably.

🌐

P2P Gossip

Peer discovery, block propagation, and startup chain sync across nodes.

Get started in under a minute

Clone, build, run. No external dependencies beyond OpenSSL, SQLite, and CMake.

1

Clone repository

git clone https://github.com/ktusharuxd-afk/shivrai-hon-core.git

2

Build the project

cd shivrai-hon-core && bash scripts/build.sh

3

Run the node

bash scripts/run_node.sh

4

Explore your node

Your explorer runs at localhost:8545 — local to your machine.

# Clone
git clone https://github.com/ktusharuxd-afk/shivrai-hon-core.git
cd shivrai-hon-core

# Build + test
bash scripts/build.sh

# Run node (listens on :8545)
bash scripts/run_node.sh

# Or with PoS consensus
./build/shivrai-node --consensus pos --port 8545

# Two-node P2P demo
bash scripts/two_nodes.sh
